# Island Airfields 2.2.1 client beta 1

Fully parked island aircraft are hidden from the vehicle-control map and active-unit lists. Open the airfield icon to access their four hangar bays, graphical loadouts and launch controls. Departing aircraft reappear when launch begins; landing queues, approach and taxi remain visible.

- Apply parking checks to map icons, pointer targeting and the deployed-unit overview.
- Cover Revolution aircraft sidebars, unit walls and box selection, including close map zoom.
- Remove the old parking ring and clear stale selections after parking.
- Preserve flight policy, saved landing orders, equipment changes and all four hangar bays.

**No additional SDK DLL update is required** if the installed SDK already supports aircraft refitting. For first installation, subscribe to [CC2X SDK](https://steamcommunity.com/sharedfiles/filedetails/?id=3833014670) and use the current [CC2 ModLoader](https://github.com/Dioramawhois/CC2-ModLoader/releases/tag/latest-beta), or install its DLL manually with the game closed.

Separate addon for stock CC2 and original Revolution 1.6-19/1.6-20. No Revolution files, complete game screens or gameplay DLLs are included. The native holomap background is unchanged. Remote clients and dedicated servers remain outside the verified release scope.
